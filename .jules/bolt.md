## 2024-05-27 - Supabase Many-to-Many Insert Optimization
**Learning:** In a loop saving multiple rows (like recipe ingredients), calling `.single()` iteratively inside a loop scales poorly (O(n) DB roundtrips) and leads to the N+1 query problem. This bottleneck was identified in `RecipeForm.tsx` where each ingredient fired off multiple sequential requests to check for existence, insert if missing, and insert into the bridge table.
**Action:** Replace iterative `.single()` DB lookups in a loop with batched operations. Use a batch `.in()` selection for finding existing records, deduplicate inputs, perform a bulk `.insert()` with `.select()` to retrieve any newly created IDs, and finally perform a bulk `.insert()` into the bridge table. This transforms O(n) operations into O(1) batched operations.
