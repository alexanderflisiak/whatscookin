## 2025-04-29 - React.memo is required for useDeferredValue effectiveness
**Learning:** In React, `useDeferredValue` defers passing an updated value to child components to keep the main thread responsive (like search input typing). However, if the child components rendering the list are not wrapped in `React.memo`, they will still re-render when the parent's original state updates, defeating the entire purpose of `useDeferredValue`. The parent's state update forces all children to re-render regardless of whether the deferred prop actually changed.
**Action:** When implementing `useDeferredValue` for performance optimization, always pair it with `React.memo` on the child components that receive the deferred value or are rendered within the same parent component, to ensure the expensive renders are actually skipped.
