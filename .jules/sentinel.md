## 2025-02-27 - Arbitrary File Upload via Recipe Photo
**Vulnerability:** The recipe photo upload component (`src/components/RecipeForm.tsx`) lacked file extension validation before calling `supabase.storage.upload()`.
**Learning:** Client-side file selection combined with backend-as-a-service storage integrations can create vulnerabilities if the backend relies on the client to send valid file types. Unrestricted file uploads can allow malicious actors to upload executable scripts or HTML files that could be served to other users.
**Prevention:** Implement explicit file extension whitelisting on the client side (in both the input's `onChange` and the form's `onSubmit` handlers) and ensure the storage bucket rules (which may be outside the immediate codebase) also enforce these restrictions.
