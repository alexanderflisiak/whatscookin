## 2024-05-18 - DoS via Unbounded Response Buffer in Scrape Route
**Vulnerability:** The application used `await response.text()` to parse external HTML responses without any size limit, risking Memory Exhaustion (OOM) and DoS when scraping a maliciously crafted infinite stream ("tarpit") or massively sized document.
**Learning:** This existed because `fetch` buffers the entire response in memory by default when calling `.text()` or `.json()`. The SSRF logic in place was correctly blocking bad IPs but did not account for the resource size returned by legitimate IPs.
**Prevention:** Always use streaming readers (`response.body.getReader()`) to process responses from untrusted sources incrementally. Keep track of bytes received and enforce a strict hard limit (e.g., 2MB for typical HTML) to proactively terminate excessively large payloads.
