## 2024-04-30 - Prevent DNS Rebinding / SSRF with Undici Fetch
**Vulnerability:** Node's global `fetch` resolves DNS under the hood. Verifying a URL's host (e.g., against a blocklist of private IPs) before calling `fetch` is vulnerable to Time-Of-Check to Time-Of-Use (TOCTOU) and DNS Rebinding. A malicious domain can resolve to a safe IP during validation, but resolve to an internal IP (like `127.0.0.1`) when `fetch` actually connects.
**Learning:** `fetch` cannot override the underlying `dns.lookup` directly.
**Prevention:** In Node.js/Next.js, install and use `undici`. Replace the global `fetch` with `undici.fetch` and supply a custom `undici.Agent` as the dispatcher. Intercept `connect.lookup` within the Agent to perform the DNS resolution, and check the resolved IP addresses against the blocklist *before* the socket connects. Cast the final resolved array as `dns.LookupAddress[]` to satisfy TypeScript.
