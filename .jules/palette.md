## 2026-04-24 - Added testing and bypassing notes for components with early returns
**Learning:** When testing components with early returns like `RecipeGrid` locally using Playwright without real data, temporarily bypassing the early return is necessary, but creating a temporary test page in `src/app` (not root `app`) and bypassing auth middleware is the safest way to avoid affecting the main app. If Supabase keys are missing, Next.js middleware might crash, so adding a dummy `.env.local` is required for the server to run. Always revert all temporary code and files before requesting code review.
**Action:** Create temporary test pages in `src/app` and set dummy env vars when verifying UI components that rely on authenticated or populated states, then strictly revert them.
