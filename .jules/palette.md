## 2024-05-19 - Accessible Icon Buttons & Toggles
**Learning:** In this application, many core interactions (like "Surprise Me", "Lazy Mode" filter toggles, and "Remove ingredient" actions) are implemented as icon-only buttons using Lucide React icons. When building these out, there's a strong pattern to forget `aria-label` attributes and keyboard focus indicators (`focus-visible:ring-2`), leaving screen reader and keyboard users without context or clear focus indication. Additionally, stateful toggle buttons lack `aria-pressed`.
**Action:** When creating or modifying icon-only buttons, always ensure an explicit `aria-label` is provided, add `focus-visible:ring-2` (and an appropriate ring color like `focus-visible:ring-stone-400`) to provide clear visual feedback during keyboard navigation, and apply `aria-pressed={state}` to any button that acts as a toggle.
